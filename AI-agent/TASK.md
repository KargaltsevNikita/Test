# Задача: Восстановление буквы Ё

## Описание

В русском языке есть две поистине уникальные буквы — **Е** и **Ё**. Уникальны они ещё и тем, что при замене одной на другую может полностью поменяться смысл слова. Классический пример:

> *«Осёл кушает травку»* — животное.  
> *«Осел на дно»* — совсем другое.

Или ещё точнее: слово **«все»** и **«всё»**, **«небо»** и **«нёбо»**, **«передохнем»** и **«передохнём»** — разные слова с разными смыслами.

На практике в русскоязычных текстах букву Ё повсеместно заменяют на Е — в новостях, документах, переписке. Восстановить правильное написание можно только по контексту: именно этим и предлагается заняться в данной задаче.

**Задача:** по левому и правому контексту и слову с отмеченной целевой позицией предсказать — оставить **Е** или заменить на **Ё**.

### Формат

Данные представлены в виде JSON-файла — список объектов, каждый из которых описывает один пример:

```json
{
  "left_context":  "Давайте господа певцы!",
  "word":          "поЕм",
  "right_context": "!"
}
```

| Поле | Описание |
|------|----------|
| `left_context` | Текст слева от целевого слова |
| `word` | Целевое слово с заглавной **Е**, отмечающей неоднозначную позицию |
| `right_context` | Текст справа от целевого слова |

Заглавная `Е` в поле `word` — это маркер позиции, она всегда `Е` (никогда `Ё`), независимо от правильного ответа. Например, и `поем` и `поём` будут записаны как `поЕм` — задача модели определить правильный вариант по контексту.

В обучающей выборке также присутствует поле:

| Поле | Описание |
|------|----------|
| `target` | `1` — правильная буква **Ё**, `0` — правильная буква **Е** |

## Выход

Файл `output.txt` — по одной строке на каждый пример тестовой выборки, строго в том же порядке:

```
Ё
Е
Е
Ё
...
```

Каждая строка содержит ровно одну букву: `Ё` или `Е`.
